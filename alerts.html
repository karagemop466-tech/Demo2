Live alert chats — price swings ≥ $0.10

A live alerting system for sudden swings in contract prices of ten cents or more, in either direction, across the in-scope topics (gas prices, elections, culture, crypto, golf). Two scrolling chats run side by side: all events, and a selective filter of the events a documented model likes as high-ROI. Markets are watched until they resolve yes or no; resolution notices appear in the feed.

Related: the collected jump chat renders the snapshot-based trade-print moves (tunable rule filter) as the same two-chat layout; this page is the browser-live version. A third, history-seeded variant (session b7bc848c) seeds every ≥ $0.10 move from the collector's own candlestick/tick history on load, with a documented two-tier rule model. Chat 1 · All events — every ≥ $0.10 swing + resolutions

Newest first. Pause stops polling; the browser keeps what it has. Detection is between two consecutive observations (trade prints from Get Trades or quote samples from Get Markets), so a swing that fully reverts between polls is not seen — nothing is interpolated.

Chat 2 · High-ROI model picks — selective filter

What "high ROI" means here. A transparent heuristic computed in your browser from official fields only — not financial advice, not an outcome prediction, and not an official Kalshi measure. Formula: score = 0.40·liquidity + 0.30·tightness + 0.30·price action, where liquidity = clamp(log₁₀(1+volume)÷4), tightness = clamp(1 − 2·(ask − bid)) and price action = (≥ $0.10 swings seen this session) ÷ 5, each clamped to 0–1. Cutoff for this chat: 0.60. Every input is shown in the model table below.
