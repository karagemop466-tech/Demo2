Kalshi Demo Dashboard

Tracks high-volume Kalshi events in five topics (gas prices, elections, culture, crypto, golf), shows live prices and liquidity, and lists every irregularity found. All figures come from official Kalshi API responses or docs, with links.

Executive summary

  • Data source: Kalshi Trade API, demo environment (https://external-api.demo.kalshi.co/trade-api/v2), as named in the docs. Production is available for read-only comparison.
  • What is live: the Live dashboard polls public prices, orderbook depth and candlesticks (1-minute to 1-day) for active markets. It does not trade.
  • What is verified: series, markets, orderbook and resolution fields on Markets and Resolutions. Every row links to its API response. Blanks are marked UNVERIFIED and never filled in.
  • “Highest dollar amount”: the API reports contracts traded, not dollars. The site ranks by contracts. A dollar figure needs a formula you approve (see Questions, Q2).
  • Portfolio and trading: BLOCKED. These need an authenticated demo API key that does not exist in this workspace. No trades were placed and no P&L is shown (see Portfolio).
  • Key irregularities: placeholder and search-engine settlement sources, demo-vs-production metadata differences, a documentation status-enum mismatch, a last price outside the current quote, and a one-sided quote with large open interest. Full list: Flagged for review.
  • Decisions needed from you: environment choice, definition of “dollar amount”, category mapping, risk limits, and a demo key. Options are on Suggestions (nothing is implemented until you choose).

How every value was checked

  • Each value was read from an official Kalshi API response or Kalshi’s docs (links on each row).
  • Names found on third-party sites were used only as search leads; each was then confirmed on the official API before use (e.g., KXAAAGASM, confirmed on both demo and production).
  • Blank or unconfirmed fields are left blank and marked UNVERIFIED. No values are inferred.
