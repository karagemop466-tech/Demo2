Demo environment data — not real markets

Every price, volume and resolution below comes from Kalshi's demo exchange (external-api.demo.kalshi.co). Kalshi states that demo prices and behaviour “may not be reflective of those in real markets”. See demo environment docs. No real money is involved anywhere on this site.

What this dashboard can and cannot do

✅ Live prices, volume, open interest, bid/askpublic endpoints, no key needed
✅ Orderbook depth — contracts available at each pricepublic endpoint
✅ Resolution tracking (YES / NO)Market.result, copied verbatim
✅ Price chart, seconds → hourspolled ticks + official candlesticks
✅ Market-level calibration analysisresolved markets only
⛔ Portfolio balance, fills, order placementrequires a private API key — why

Nothing on this site asks for a credential. Anything unconfirmed is blank and listed on Flagged for Review.
