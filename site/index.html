Kalshi Demo Dashboard

Live, interactive tracking of Kalshi prediction markets across gas prices, elections, culture, crypto, and golf — with price-movement charts, liquidity depth, portfolio performance, trade categorization, strategies, and a reviewable suggestions board.

Data sources. All endpoints and signing are verified from the official Kalshi API documentation (docs.kalshi.com). Every table row carries a source link. Values that cannot be confirmed from an official source are left blank and flagged as unverified — never inferred.

Executive summary

The dashboard is a two-part system: a Node backend that signs and calls the Kalshi demo REST/WebSocket API, executes trades, and tracks events until resolution (YES / NO); and this clean static site for GitHub Pages that works standalone on public market data. See docs/EXECUTIVE_SUMMARY.md and the Suggestions board for improvement paths.
