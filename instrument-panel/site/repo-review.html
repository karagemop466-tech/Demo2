Repository review

A line-by-line review of what is already in this repository against the official Kalshi documentation. Each item states what the file claims, what the official source says, and whether the two agree. Where a documentation URL was checked, the outcome of that check is recorded.

Summary of irregularities

  • Topic classification by keyword (assets/app.js) is not how Kalshi classifies; replaced in the new site.
  • Balance-in-cents assumption is a pre-migration shape and is unverified.
  • At least one documentation path in the root pages is wrong (plural /markets/).
  • Three overlapping dashboard implementations exist in one repository.
  • An open PR (#6) aims to remove a credential form that main may still contain.
