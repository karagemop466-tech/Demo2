Account performance · paper trading

Portfolio, trades and outcomes

This page offers a local paper-trading simulator that needs no credentials and records simulated trades in this browser. Authenticated account access and live order submission are intentionally disabled on this static site — a public GitHub Pages app has no trusted server to protect a private signing key, so enabling them requires a separately secured backend. No account value is ever fabricated.

Why authenticated access is disabled. A static site cannot hold a private signing key safely — anyone who can load the page can read it. Browser-side key entry would expose the key to site scripts. Portfolio reads and demo order execution are therefore turned off; this trade-off is recorded as decision Q-2 on Questions. See Suggestions for the backend-based path.

Pick a ticker from the live console (click a row, then read the ticker under the chart). Price is what you would pay per contract, $0.01–$0.99.

Payout rule used for settlement: a winning contract pays $1.00, a losing contract pays $0.00, so P&L = (result matches side ? count : 0) − price × count. That is the documented binary payout (market settlement) without fees, which are zero for simple yes/no settlement.

Authenticated account access · disabled

Account connection is intentionally disabled

requires a secured backend

This site is a static GitHub Pages application. It has no trusted server to protect signing credentials. Do not paste an API key or private key into this site. A browser-side key-entry and trading flow would expose a powerful secret to site scripts and any compromise of the hosting origin.

Portfolio values, positions, fills, settlements and trade performance are therefore blank—not estimated—and order submission is not available. No account data is fabricated.

To enable this safely, review the proposal on Suggestions: build a separately hosted backend that stores credentials in a secret manager, authenticates the account owner, limits demo access, validates orders, and logs activity. Until then, use Kalshi's official demo interface directly.
