5 · Limits of this verification

  • The values were verified against the demo environment only. Nothing here says anything about production markets.
  • The collector reads the public endpoints without credentials, so it cannot see anything an account holder can see: balance, positions, fills, settlements or order state.
  • Listings are read at a point in time. Kalshi states that responses are cached briefly, so a value can lag the exchange by several seconds.
  • Markets that settled before the historical cutoff are only available through the separate historical endpoint, so the resolution table covers the recent window only. Flag F17
  • Every remaining uncertainty is listed on the Flagged for Review page.
