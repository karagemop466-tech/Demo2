Rule for this project: a value is published only if it can be traced to an official Kalshi source. Each row below states the claim as it appears on the site, how it was checked, the official source, and the result. Rows with a “not confirmed” result are either omitted from the site or shown as “—” and listed on the Flagged for Review page.

3 · Repeatable verification

The checks above were made from a build session. They are repeated automatically: the workflow .github/workflows/refresh-data.yml calls the same demo endpoints on a schedule, records every URL, page count and error in data/meta.json, and the workflow log is the audit trail. The script that performs the calls is scripts/refresh-data.mjs in this repository — read it to check exactly what is requested.
