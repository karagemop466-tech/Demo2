C. Unverified values policy

Any value that could not be confirmed from an official source is left blank and marked UNVERIFIED in the tables — it is never inferred or filled in. Dated snapshot values (in Verified Tables and dashboard tables) each carry the API URL they were read from; re-verification status is recorded on the Verification page.
