Account & execution

Portfolio performance, trade execution and trade categorisation

Everything on this page runs against the Kalshi demo environment with mock funds. The build session had no Kalshi account, so no account figures are pre-filled here: each value below appears only after you connect your own demo key, and stays blank otherwise.

Current state: not connected, and no trades have been placed. A Kalshi demo account can only be created by a person at demo.kalshi.co/sign-up (mock details are allowed, but the sign-up needs an email address and a password). That step could not be automated, so the tables below are empty by design rather than filled with invented numbers. The trade execution, categorisation and performance code is complete and tested — it activates the moment a key is supplied. See Questions, item Q1.

Path A — local command line (recommended)

The private key never enters a browser. The signing implementation is tools/kalshi_trade.py, and its signature format is checked offline by tools/test_signing.py.

StepCommand
1 · create a key pairopenssl genpkey -algorithm ed25519 -out kalshi.key
openssl pkey -in kalshi.key -pubout -out kalshi.pub
2 · register the public keypaste kalshi.pub into Account → API Keys in the Kalshi demo UI, then copy the Key ID and the downloaded private key
3 · check the accountpython3 tools/kalshi_trade.py --key kalshi.key --key-id <KEY_ID> balance
4 · list positions and fillspython3 tools/kalshi_trade.py --key kalshi.key --key-id <KEY_ID> positions
python3 tools/kalshi_trade.py --key kalshi.key --key-id <KEY_ID> fills
5 · place a demo orderpython3 tools/kalshi_trade.py --key kalshi.key --key-id <KEY_ID> place --ticker KX…-… --side yes --count 10 --price 0.42
6 · read the local trade logpython3 tools/kalshi_trade.py log

Path B — in-browser signer (opt-in)

The PEM below is imported into this browser's WebCrypto and used only to sign requests that go straight from your browser to external-api.demo.kalshi.co. The key is never uploaded, never written to the server, and is discarded when you disconnect or reload. Because this page is served from a public GitHub Pages site, treat it as a convenience for a demo account only — prefer Path A for anything that matters.
