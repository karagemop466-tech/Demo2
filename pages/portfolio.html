Portfolio & Trading

Account connection is intentionally disabled

This site is a static GitHub Pages application. It has no trusted server to protect signing credentials. Do not paste an API key or private key into this site. A browser-side key-entry/trading flow would expose a powerful secret to site scripts and any compromise of the hosting origin.

Portfolio values, positions, fills, and trade performance are therefore blank—not estimated—and order submission is not available. No account data is fabricated.

To enable this safely, review the proposal on Suggestions: build a separately hosted backend that stores credentials in a secret manager, authenticates the account owner, limits demo access, validates orders, and logs activity. Until then, use Kalshi's official demo interface directly.
