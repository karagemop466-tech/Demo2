Demo account

Portfolio performance and demo trade execution

Connect your demo Kalshi account to load balance, positions, fills and settlements, and to place demo orders. Requests are signed in your browser exactly as Kalshi documents (quick start: authenticated requests).

Security notice — read before connecting

This site is a public static page. Your private key is held in the page's memory only: it is never written to localStorage, sessionStorage or a cookie, and it is used for nothing except producing the request signature. It is still a public page, so treat it as a demo-only tool and use a demo key with the smallest useful scope. For production use, or to hold funds, put the signed calls behind a private backend with a secret manager — see suggestion S2. Never reuse a production key here.

1 · Connect a demo account

Create a key at demo.kalshi.co → Account & security → API Keys. Kalshi issues RSA (PKCS#1) or Ed25519 keys; see Generate API Key.
