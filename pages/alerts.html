Live alerts — sharp price moves

A simplified scrolling chat for every move of $0.10 or more between two consecutive contract prices, in either direction, on in-scope markets (gas, elections, culture, crypto, golf). Two chats: everything, and a rule-filtered “high-ROI” view of the same swings. Each message links the market's own API page so a move can be checked against its timestamp; the cause of a move is never guessed — see Cause channels for where to look.

Model picks — high ROI rule-based

The model is a documented two-tier rule over the same swings, not a learned system: Tier A · high ROI — swing ≥ $0.10 that lands at a price between $0.15 and $0.85 (room to run in both directions); Tier B · traded snap — swing ≥ $0.30 that lands at ≤ $0.05 or ≥ $0.95 on a market with volume ≥ 1,000 contracts (conviction repricing on real flow). Not financial advice; no backtested performance is claimed. Criteria and trade categorisation live on Analysis.

Where the messages come from: (1) on load, every ≥ $0.10 move inside the collector's official candlesticks and tick history (data/history.json) is seeded into the chat, labelled collector history; (2) after load the page polls GET /markets/trades on the demo API every 25 seconds (market-data endpoints need no authentication — docs) and turns new trade prints into alerts, labelled live trade print. If the browser cannot reach the API (offline, rate-limited), the chats keep the seeded history and the status card says so. Alerts persist in this browser only (localStorage); “Clear” empties them. Up to 200 are kept.
