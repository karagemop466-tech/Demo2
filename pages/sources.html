Committed data in this repository

The scheduled collector writes these files; they are the fallback when a browser cannot reach the API. Each row inside them carries the API URL it was read from.

FileContents
data/meta.jsonCollection metadata, scope rules, counts and the API base used
data/markets_open.jsonEvery in-scope open market, with its source URL
data/markets_settled.jsonEvery in-scope settled market with its official result
data/events_open.jsonEvent-level rows
data/series_scope.jsonSeries with category, tags, fee parameters and settlement sources
data/orderbooks.jsonOrderbook snapshots for the highest-notional markets
data/taxonomy.jsonThe official tag taxonomy as returned
data/collection_log.jsonEvery request the collector made: URL, status, timestamp, byte count
data/kalshi_snapshot.jsonEarlier hand-curated snapshot kept from a previous session (24 rows, first page of each query)
data/api_market_samples.jsonEarlier session's sample market rows, each with the query it was read from
data/api_reverification.jsonEarlier session's per-ticker re-verification of series and event records
data/api_settlement_sources.jsonEarlier session's settlement-source list, with URLs that were not opened blanked and flagged
