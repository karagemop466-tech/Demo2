API reference - verified line by line

Every value this site displays comes from one of the endpoints below. Each row was checked against the official Kalshi documentation page linked in the row on 2026-11-20. No third-party documentation, blog post or memory was used.

Two findings that changed the build.
1. The legacy order path POST /portfolio/orders has been removed and now returns 410 Gone (deprecated_v1_order_endpoint). Trade execution uses POST /portfolio/events/orders instead.
2. The order book returns bids on both sides only - no asks. A YES ask at price x is a NO bid at 1 - x, so the dashboard's ask column is derived and labelled that way rather than presented as a raw field.
