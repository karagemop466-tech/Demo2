5. Limits you should know before using this page

  • Cause links are not provided. No official Kalshi source links a price move to news. Adding news links would be inference, so the column stays blank.
  • Thin prints can look like jumps. A single 0.01-contract print can move the last price. Check the contract counts in table 1.
  • Same-timestamp prints. When two prints share a timestamp, their order is unknown, so a move between them is shown with a flag.
  • No intraday resolution for snapshots. The snapshot detector cannot see a move shorter than the gap between snapshots. A WebSocket trade feed would fix this; see the flags page.
  • Time window selector. This page is a static build of the collected data. Choosing seconds, minutes or hours at run time needs the live feed, which is listed as a suggestion, not built here.
