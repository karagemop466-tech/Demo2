Method (read before interpreting numbers)

  • Ranking metric — est_dollar_volume_24h = Σchild markets volume_24h_fp × last_price_dollars. This is a computed estimate, not an official API field: the API exposes 24h volume in contracts and a last price in dollars, but no dollar-turnover field (Get Markets). Official contract volumes are shown alongside, unmodified.
  • Topic classification — gas prices: series ticker KXAAAGAS* / scope Gasoline / title contains “gas price”; elections/culture/crypto: series or event category; golf: series tags contains Golf or title contains “golf”. Categories verified via Get Series List.
  • Source per row — every row links to the exact official API URL the data came from. Values that cannot be confirmed stay blank.
