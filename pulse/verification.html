Verification & source register

Official Kalshi documentation and demo API data are the only evidence for product/API behavior and market values. Derived values are explicitly labeled as computed arithmetic. This subsite's snapshots came from the repository collector; static values are a dated snapshot, not an assertion of current conditions.

Verification boundary. In this sandbox no Kalshi API host is reachable directly, so the pulse engine reads committed, previously collected official API snapshots. Do not interpret a snapshot as currently live. The browser chart attempts the public demo REST API directly and shows a status/fallback if unavailable. Authenticated balance/orders are not exposed because no key is configured.
