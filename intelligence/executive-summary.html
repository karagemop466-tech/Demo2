6 · Methodology (short form)

  1. Enumerate official categories/tags, then enumerate series per topic query (completeness recorded per query: complete vs partial).
  2. Capture live events (status=open) and settled events (status=settled) for watchlist series; capture orderbooks, candlesticks and trade ticks from the official endpoints.
  3. Transcribe values verbatim into data/*.json with the source URL on each record; blanks stay blank.
  4. The dashboard prefers live data (browser → demo API) and uses the verified snapshots when the browser cannot reach the API; mode is always displayed.
  5. Anything unverified, derived, or anomalous is listed on Flagged for Review — it never blocks the site, but it is never hidden either.
