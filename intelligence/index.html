Verification model

"Never infer or fill in values" is enforced structurally, not just by policy.

Every table row carries a source link to an official endpoint (api demo host) or official documentation page (docs.kalshi.com). Rows are rendered directly from data/watchlist.json and data/snapshot.json, whose records each embed the exact URL the values were read from.
Unconfirmable values stay blank and are rendered as "— blank (unverified)" in amber. Nothing is estimated, back-filled or averaged. Derived metrics (e.g. estimated dollar volume) are labelled derived with the formula shown, and are additionally listed on the Flagged page.
Demo ≠ production. Official docs state demo prices and behaviour "may not be reflective of those in real markets" — docs.kalshi.com/getting_started/demo_env. Treat all figures as demo-environment facts only.
