What this verification does not cover

  • Portfolio, position, fill and order values: those endpoints need a Kalshi API key (API keys). No key exists in this repository, so every portfolio row stays blank and flagged rather than filled in.
  • The cause of a price move. Kalshi publishes no news feed in the Trade API, so no official source can confirm why a price moved; the column stays empty.
  • WebSocket traffic: the demo WebSocket handshake requires signed headers (Quick Start Websockets), so the browser pages use the REST endpoints, which need no credential.
