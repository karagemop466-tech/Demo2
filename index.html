Kalshi demo market dashboard

A dashboard for Kalshi's demo exchange covering five topics only — gas prices, elections, culture, crypto and golf. Every price, volume and resolution is copied from an official Kalshi API response, every table row links back to the response it came from, and anything that could not be confirmed is left blank and listed for review.

This is the demo environment

Data comes from external-api.demo.kalshi.co. Kalshi states that demo prices and behaviour “may not be reflective of those in real markets”. No real money is involved. Not financial advice.

How the data gets here

A GitHub Actions workflow calls the public Kalshi demo API every 15 minutes, checks the result (a source link on every row, prices inside $0.00–$1.00, derived dollar values reconciling with their inputs, snapshot younger than six hours) and commits the snapshot. Your browser also polls the same API directly for live prices; a probe with Origin: karagemop466-tech.github.io returned that origin in access-control-allow-origin, so no proxy is needed for public data.
