Long windows use official candlesticks (Get Market Candlesticks, period 1 min / 1 h / 1 day, max 5,000 periods per request). Short windows use the collector's own tick history, which is sampled every 10 minutes — a 60-second window will legitimately be empty. Nothing is interpolated.

Sharp price moves — jumps ≥ $0.10 between consecutive price points

Each red marker on the chart is a move of $0.10 or more between two consecutive points. The API returns price and volume but not the news or event behind a move, so the cause is not inferred — each row links to the market's own page on Kalshi and is flagged cause unverified. The possible context column is only a news-search link that may be related; it is not an official source and asserts nothing.

Liquidity — contracts available at each price

Raw bids from Get Market Orderbook. Kalshi returns yes bids and no bids only; a NO bid at price p is the same as a YES ask at 1 − p, so the ask side here is derived and labelled as such.

Markets ranked by estimated dollar volume

What "highest dollar amount" means here. The Trade API has no single dollar-volume field. Every row therefore shows the raw official fields (volume_fp, open_interest_fp, last_price_dollars) and one clearly-labelled estimate: volume_fp × last_price_dollars. Rows missing lifetime volume_fp (top-event lead markets) show a blank there and a labelled 24h estimate beside it. Coverage note: the snapshot unions every source-linked market set and is not a complete enumeration of the exchange (see the adapter.coverage field in data/snapshot.json). See Flagged F2 and Q1.
