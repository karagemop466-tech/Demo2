Kalshi demo dashboard — start here

One dashboard for the five topics the brief names — gas prices, elections, culture, crypto and golf — with price charts, order-book liquidity, resolution tracking (yes or no) and simulated-trade analysis, built from Kalshi's public demo Trade API. Mock money only; nothing here is investment advice.

What every number on this site is. Either (a) a value copied verbatim from a Kalshi API response, (b) arithmetic over copied values, labelled as computed (e.g. 24-hour dollar volume from trade prints), or (c) blank. A value that could not be confirmed is left blank and listed on Flagged for Review — it is never filled in from memory or guessed. Each table row links to the request it came from.

How to use this in a trading workflow

StepPageWhat to look atWhy it is the right page
1Live dashboard Ranked markets, the price chart (X = time, Y = contract price), the order book and the liquidity-over-time chart. It is the only page with both the ranking and the two charts on one screen, so a candidate is judged on price AND on whether it can actually be traded.
2Topic pages All live events for one topic, then everything already resolved for it. Keeping topics apart stops a golf long-shot being compared with a gas price market.
3Resolutions How each event resolved, YES or NO, and how much of it ever traded. A YES on a market with zero volume is not evidence about anything; the page says so.
4Cause channels The settlement sources Kalshi itself names for each contract, and the steps to line a $0.10+ move up against the news. The API never says why a price moved, so the honest answer is a checklist, not a headline.
5Analysis Per-trade P&L, five categorisations, and strategies gated behind a minimum sample. Strategy claims below the sample threshold are refused rather than shown as findings.
