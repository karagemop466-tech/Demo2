Portfolio & Trades

Status: blocked, needs your action. Reading your demo portfolio, placing trades, and tracking trade performance require a Kalshi demo account and an API key. This session cannot create either one without logging in to Kalshi.

What is needed (one-time setup)

  1. Create a Kalshi demo account. Kalshi's guide: help.kalshi.com, creating and using a demo account. Demo site: demo.kalshi.co.
  2. Generate an API key for that demo account. Kalshi's docs: API Keys. The docs say the key process is the same for demo and production, and demo credentials are separate from production.
  3. Add the key to a secret store (not to this repository). The repository must never contain credentials.

Authenticated endpoints and their signing rules are in the Quick Start: Authenticated Requests guide. Trading endpoints are described in Quick Start: Create your first order. These were not read in full during this session.

Strategy categories proposed for analysis (not yet tested)

These are candidate groupings for classifying trades once data exists. They are a plan, not a result. Each one needs a pre-set hypothesis before testing.

  • By topic: gas prices, elections, culture, crypto, golf (matches the category pages).
  • By entry price band: low (under $0.20), middle ($0.20 to $0.80), high (over $0.80). Band edges are a proposal.
  • By time to close: under 1 day, 1 to 7 days, over 7 days.
  • By liquidity at entry: contracts available at the entry price, from the orderbook.
  • By settlement-source quality: single official source vs. multiple or unclear sources (see flags F-03, F-05, F-09).
