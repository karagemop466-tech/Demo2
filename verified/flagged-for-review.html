Flagged for Review

Irregularities, unverified items, and open issues. Each one has the source links for manual review. Flagged items do not block the site or the merge. They are listed here so you can review them after the site is live and request changes.

Data flags

F-01

Demo data looks synthetic or placeholder

Severity: high

Demo events include close dates in 2099 (e.g., KXNEXTNATOSECGEN-99 and KXELONMARS-99 with close_time 2099-01-08 and 2099-08-01) and a custom_strike field reading 'demo strike'. Kalshi says demo prices 'may not be reflective of those in real markets'. None of these rows should be treated as a real-market signal.

Sources for manual review:

  • Kalshi demo environment doc
  • Events API response (observed)

Status: needs review. Does not block the site.

F-02

'Highest dollar amount' cannot be read from volume fields

Severity: high

Kalshi's volume_fp and open_interest_fp are contract counts ('_fp' = contract quantity), not dollars. Prices are in '_dollars' fields. A dollar-volume figure would have to be computed from trade prices times contracts (for example from the Trades endpoint). That computation is not done yet.

Sources for manual review:

  • Fixed-Point Representation
  • Get Market (volume_fp definition)

Status: needs review. Does not block the site.

F-03

Settlement source does not match the contract

Severity: medium

KXRIQUAHOG (Rhode Island quahog landings) lists a Federal Reserve Bank of New York SOFR page as its settlement source. A SOFR page does not describe shellfish landings. Row kept off the public tables. Needs review of the contract terms PDF before any use.

Sources for manual review:

  • Series API (observed)
  • Contract terms PDF

Status: needs review. Does not block the site.

F-04

Ticker and title disagree

Severity: medium

KXBTCMAX130 has the title 'When will bitcoin hit 100k?' but its ticker suffix (MAX130) and its contract-terms file (BTCMINMAX.pdf) do not match that title. The threshold must be confirmed in the contract terms before using the series.

Sources for manual review:

  • Series API (observed)
  • Contract terms PDF

Status: needs review. Does not block the site.

F-05

Placeholder and search-engine links in settlement sources

Severity: high

KXXBANNEDMURRAYHILLGUY1 and KXXBANNEDGROK list settlement-source names with unfilled template text (for example 'account holder of', 'official social media accounts of or their official representatives'), and some entries link to Google search pages rather than to a named source. Settlement rules for these series are unclear from the API.

Sources for manual review:

  • Series API (observed)
  • Contract terms PDF

Status: needs review. Does not block the site.

F-06

Gas-price series listed without a market-level snapshot

Severity: low

The AAA gas series rows come from the series list. A market-level price for these series was not returned by a market query during collection (markets?series_ticker=KXAAAGASDTN&status=open returned an empty list). Current prices are therefore not in the table.

Sources for manual review:

  • Get Markets endpoint doc
  • Series API (observed)

Status: needs review. Does not block the site.

Severity: medium

Some news-outlet names link to different domains than their names suggest (for example 'The Washington Post' linked to abc.com on KXNEWPOPE-70, and 'ABC' linked to abc.net.au, an Australian site). The NATO event is dated to 2099 in the demo data (see F-01).

Sources for manual review:

  • Events API (observed)

Status: needs review. Does not block the site.

F-11

Category naming: 'Culture' and 'Golf' do not match Kalshi's tag list

Severity: high

The series endpoint returns a category named 'Culture', but Kalshi's tags_by_categories endpoint has no 'Culture' key. Golf appears only as a tag under Sports. Filters were built on the observed values, so the Culture and Golf pages may differ from what Kalshi's own site shows.

Sources for manual review:

  • Tags by categories (observed)
  • Series API category=Culture (observed)

Status: needs review. Does not block the site.
