Kalshi Demo Dashboard

A read-only dashboard built from the Kalshi demo API. It collects contracts for five topics (gas prices, elections, culture, crypto, golf), records their sources, and lists what is still missing before any trading decision.

Demo environment only. Kalshi says demo prices "may not be reflective of those in real markets." Nothing here is a trading recommendation.

Executive summary

  • What works: Public, unauthenticated market-data reads from the demo Trade API return verified data. Every row on the category pages links to the API response it came from.
  • What is in the data: 24 rows: 2 AAA gas-price series, 6 elections rows (4 series, 2 events), 2 culture series, 9 crypto series, 5 golf series. Each category is the first page of results only, not a full list.
  • Biggest limits: demo data includes 2099 close dates and placeholder-looking settlement sources (see Flagged for Review). Volume fields are contract counts, not dollars, so the "highest dollar amount" ranking cannot be read directly.
  • Blocked without your action: Portfolio tracking, trade execution, and per-trade performance need a Kalshi demo account and API key. Creating those requires logging in to Kalshi, so they are not done. See the Portfolio & Trades page.
  • Next decisions: review the Suggestions and answer the open Questions. No implementation changes are made until you choose.
