What the dashboard measures

Every displayed live value is taken from the demo API or calculated using the explicit formulas below. Missing or unavailable source values remain blank; no example payloads are presented as live data.

Topic matching rules

Topic labels are this project’s navigation groups, not claims that Kalshi uses these exact categories. An event can appear in more than one group if more than one term matches. Unknown or unmatched events are not assigned to a topic. The phrases are intentionally visible in source code and can be adjusted after the topic coverage review.

PageCurrent matching approachReview noteOfficial metadata source
Gas pricesGas, gasoline, natural gas, or fuel-price terms found in event category, title, subtitle, or ticker text.Plain “gas” matching may include adjacent gas markets that are not retail pump-price forecasts; confirm the intended scope.Event category/title fields ↗
ElectionsElection, presidential, midterm, primary, runoff, ballot, nominee, gubernatorial, or senatorial terms.Keyword rules can miss candidate/office markets that omit an election term and can include non-election forecasts. Validate against current series metadata.Event category/title fields ↗
CultureCulture/entertainment category or explicit film, TV, music, award, artist, streaming, or related terms.“Culture” is broad; agree whether awards, celebrity, media, and entertainment are included.Event category/title fields ↗
CryptoCrypto category and explicit crypto/asset terms such as Bitcoin, BTC, Ethereum, ETH, Solana, and token.Confirm the asset universe, whether stablecoins and blockchain-company events belong, and how ticker abbreviations should be handled.Event category/title fields ↗
GolfGolf, PGA, LPGA, Ryder Cup, Masters, or Open Championship terms.“Masters” can be ambiguous; false-positive risk remains unless event category/series context is validated.Event category/title fields ↗
