Source-linked market monitor, not a trading bot

This repository now contains a source-linked static dashboard for selected Kalshi demo markets, plus a requirements and decision register. The live market surface is public-data-only. Account portfolio access and order execution are deliberately not represented as available.

Executive readout

Public demo market monitor

The dashboard is wired to request open events and binary markets from Kalshi’s recommended demo Trade API. Its client code filters for gas prices, elections, culture, crypto, and golf; ranks events by a documented calculation from visible YES/NO bid depth; displays per-price contract quantities; requests price-history charts; and provides a browser-local watchlist for following markets through settlement. The demo API’s live response and browser CORS behavior have not yet been confirmed from this workspace.

Unavailable in this build

Portfolio connection and execution are not enabled

No demo account credentials, API key, private signing key, portfolio history, or user authorization were available in the repository or task context. Therefore no portfolio numbers are shown, no trade was submitted, and no trade-performance result is claimed. The site does not ask for, store, or embed secrets.

What “highest dollar amount” means here

The current leaderboard sorts by displayed bid-side notional: across an event’s active binary markets, add each returned YES and NO bid price multiplied by the contracts resting at that price. The official book supplies price/quantity levels; the dollar amount is a transparent calculation. It is not a Kalshi-provided event-level traded-dollar-volume field, total trade turnover, expected payout, or guarantee that the displayed orders will remain available. The 24-hour volume column is labeled in contract counts and is not converted into dollars.

Before using the ranking as the primary “highest dollar amount” signal, decide whether the intended comparison is displayed book depth, executed dollar volume, open interest, or some other measure. That decision and its source limitations are recorded on Flagged for Review.
